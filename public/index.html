Questions

Is Vortex free?

Yes. The client, the Plus Addon and the launcher are free.

Which Minecraft versions are supported?

26.2, 26.1.2, 26.1.1 and 1.21.11 with Fabric, and 1.8.9 with Legacy Fabric. The Plus Addon (cheats and bots) is available for every version except 1.8.9.

Can I get banned?

For cheats: yes, on most servers. Every cheat shows its ban risk. The normal client features – HUD, PvP tools, performance, music – are made for regular play.

Windows says the installer is unknown. Is that safe?

Windows SmartScreen warns about every new program that is not signed with a paid certificate. Download only from this page or from our GitHub releases; you can check each mod file with its SHA-256 shown above.

Does it work on Mac or Linux?

The launcher is for Windows. On Mac and Linux, install Fabric yourself and add the mod files from the download section.

Does it work with Sodium and Iris?

Yes. The launcher can install Iris and Sodium for shaders. If a Vortex module misbehaves with Sodium, turn both off again in the launcher.

Where do I get help?

On our Discord server. Post your question there – with a screenshot or the launcher log if something does not start.
